# Zazu 1212 deployment

The repository includes a fixed-supply ERC-721 collection and a direct website mint for Robinhood Chain.

## Locked collection settings

| Setting | Value |
| --- | --- |
| Name | Zazu Cat 1212 |
| Symbol | ZAZU |
| Maximum supply | 1,212 |
| Mint price | 0.003 ETH |
| Default maximum per transaction | 12 |
| Default lifetime maximum per wallet | 24 |
| Token IDs | 1 through 1,212 |
| Mint proceeds | Deployment payout wallet |
| Royalties | None |

The contract is a lazy mint. Buyers mint their own NFTs and pay their own mint gas. The deployer does not pre-mint 1,212 tokens.

Token IDs are sequential archive numbers. The collection does not promise randomized rarity. Final metadata should be published before the sale opens so buyers can inspect what they are minting.

## Before deployment

1. Put at least 0.01 ETH on the deployer wallet on Robinhood Chain. This is a deployment buffer, not the mint price.
2. Upload the final 1,212 images and `1.json` through `1212.json` metadata files to permanent storage.
3. Check token 1, a middle token, and token 1212 before using that folder as `NFT_BASE_URI`.
4. Copy `deploy/zazu-1212.env.example` to `.env.nft.local`. This filename is ignored by Git.
5. Add the real private key only to `.env.nft.local`. Never add it to Vercel, Railway, a ticket, chat, or Git.

The base URI must end in `/`. For example, `ipfs://bafy.../metadata/` resolves token 1 to `ipfs://bafy.../metadata/1.json`.

## One-command deployment

Keep `NFT_START_SALE=false` for the safest deployment. From the repository root:

```bash
set -a
source .env.nft.local
set +a
npm run nft:deploy
```

The script refuses to broadcast anywhere except Robinhood Chain ID 4663. It deploys, prints `ZAZU_NFT_CONTRACT_ADDRESS`, then attempts verification through Blockscout.

If Blockscout is temporarily unavailable, the deployment is still complete. Do not run `npm run nft:deploy` again because that would create a second collection. Keep the same environment loaded and resume verification without broadcasting a duplicate:

```bash
npm run nft:verify
```

If the final metadata is already pinned and checked, set `NFT_BASE_URI` and `NFT_START_SALE=true` before running the same command. That makes the mint usable immediately while tokens remain unrevealed.

## Connect the website

Add only these public values to the Vercel project, then redeploy:

```dotenv
NEXT_PUBLIC_NFT_CONTRACT_ADDRESS=<ZAZU_NFT_CONTRACT_ADDRESS_FROM_THE_SCRIPT>
NEXT_PUBLIC_ROBINHOOD_RPC_URL=https://rpc.mainnet.chain.robinhood.com
```

The site will then read the minted total and sale status from the contract, connect an injected EVM wallet, switch it to Robinhood Chain, calculate the exact mint value, submit `mint(quantity)`, and link the receipt on Blockscout.

## Owner operations

Export the collection address and the key for the configured `NFT_OWNER`. If `NFT_OWNER` was left blank, this is the deployer key:

```bash
export ZAZU_NFT_CONTRACT_ADDRESS=0x...
export NFT_OWNER_PRIVATE_KEY=0x...
```

Open or close the mint:

```bash
cast send "$ZAZU_NFT_CONTRACT_ADDRESS" "setSaleActive(bool)" true \
  --rpc-url "$ROBINHOOD_RPC_URL" --private-key "$NFT_OWNER_PRIVATE_KEY"
```

Set the final metadata folder and reveal:

```bash
cast send "$ZAZU_NFT_CONTRACT_ADDRESS" "setBaseURI(string)" "ipfs://bafy.../metadata/" \
  --rpc-url "$ROBINHOOD_RPC_URL" --private-key "$NFT_OWNER_PRIVATE_KEY"

cast send "$ZAZU_NFT_CONTRACT_ADDRESS" "reveal()" \
  --rpc-url "$ROBINHOOD_RPC_URL" --private-key "$NFT_OWNER_PRIVATE_KEY"
```

Freeze metadata only after checking several live token URIs. Freezing cannot be undone:

```bash
cast send "$ZAZU_NFT_CONTRACT_ADDRESS" "freezeMetadata()" \
  --rpc-url "$ROBINHOOD_RPC_URL" --private-key "$NFT_OWNER_PRIVATE_KEY"
```

Withdraw mint proceeds to the configured payout recipient:

```bash
cast send "$ZAZU_NFT_CONTRACT_ADDRESS" "withdraw()" \
  --rpc-url "$ROBINHOOD_RPC_URL" --private-key "$NFT_OWNER_PRIVATE_KEY"
```

Transfer ownership with the inherited two-step flow when a multisig is ready. The new owner must separately call `acceptOwnership()`.

## What is not generated by this repository

The current repository contains the 40-image Zazu preview sheet, not 1,212 final standalone artworks. The contract and website are deployment-ready, but the sale must not be presented as a finished 1,212-art collection until those final images and metadata files exist and have been pinned.
